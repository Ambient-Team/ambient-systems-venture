# Ambient Systems - Venture Timeline (2020-2026)

A chronological record of the Ambient Systems venture: smart-building / indoor-climate IoT and machine learning, from the 2020 applications (YC, NUS GRIP Run 4) through the Singapore company, accelerators (SMU, ACE, Panasonic Deep Tech Challenge), the Hong Kong, Canada/Quebec and Japan explorations, to 2026. As of October 2026, Ambient Systems Ltd (Hong Kong) is the sole active entity; the Quebec entity is closed and the Singapore company was struck off in May 2026.

**This repository is private.** A separate **public** repository will be seeded from an orphan `public-snapshot` branch after review. Internal readiness tooling lives under `_private-tooling/` (excluded from any public export).

## Layout
- `TIMELINE.md` / `timeline.csv` - milestones with links into the phase folders.
- `YYYY/<phase>/YYYY-MM-DD <title>.<ext>` - documents, PDFs, spreadsheets, text/code and small images, renamed with their best-known event date (`-00` = only the month or year is known).
  - 2020/2020-04 Origin and first applications
  - 2020/2020-07 NUS GRIP Run 4
  - 2021/2021-H1 NUS GRIP Run 5 and spin-out
  - 2021/2021-H2 Singapore company - patents and accelerators
  - 2022/2022 Singapore accelerators - SMU ACE Panasonic
  - 2023/2023 Panasonic DTC and Hong Kong discovery
  - 2024/2024 Hong Kong and Quebec - data platform
  - 2025/2025 Global version - HK Canada Japan
  - 2026/2026 Agency model and wind-down
- **Releases** - one zip per phase (tag `phase-YYYY-MM` / `phase-YYYY-H1` / `phase-YYYY`) with videos, bulky image/media folders and very large decks. See `SIZE-PLAN.md`.
- `EXCLUSIONS.md` - what is deliberately not here and why.
